CASE 01 // TELEMETRY & CLOUD PIPELINE

Intelligent IoT-Based ECG Monitoring System

Academic Prototype IoT Pipeline

An IoT-based ECG monitoring prototype that acquires real-time cardiac signals using an AD8232 analog front-end sensor and Arduino microcontroller, transmits packetized telemetry through cellular connectivity (SIM7000E / SIM800L), and integrates a cloud backend with Firebase for resilient remote data storage. The broader research explores AI-assisted myocardial infarction classification and mobile telemetry monitoring (concept explored in Flutter).

AD8232 ECG Sensor → Arduino Microcontroller → SIM7000E / SIM800L → Node.js / Firebase → AI Classification Concept

CASE 02 // EDGE COMPUTING & DEEP LEARNING

Edge AI ECG Classification

Edge Inference 1D-CNN

An edge AI research and implementation project exploring binary myocardial infarction classification directly from digitized ECG signals using a lightweight 1D convolutional neural network (1D-CNN). The work involves training and validating on the benchmark PTB-XL clinical dataset, performing model evaluation and post-training quantization with TensorFlow Lite, testing interpretability via Grad-CAM saliency maps, and addressing deployment constraints on a Raspberry Pi.

PTB-XL ECG Dataset → 1D-CNN Model Architecture → Grad-CAM Saliency → TFLite Quantization → Raspberry Pi Edge Testing
